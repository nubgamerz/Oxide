## What's fixed

- **Copy and paste notes in the piano roll.** Ctrl+C and Ctrl+X in the piano roll now copy or
  cut the selected notes, and Ctrl+V pastes them at the playhead, the first note exactly where
  the playhead is and the others in the same places around it. Before, these keys copied the
  whole MIDI clip and pasted a copy of the clip instead. The Edit menu's Cut, Copy and Paste do
  the same after a click in the piano roll.
- **A track's render starts at the start of the song.** Render track… now writes a file that
  begins at the very start of the song, silent until the track's first sound, and puts it at
  the start of the new track. Rendered files line up with each other and with the song, so
  you can load them into a new project and they play in time. Before, the file started at the
  track's first clip.
- **Files open in the Waveform view reopen with the project.** Open a file in the Waveform
  view (a double-clicked clip, any audio file, or a mixdown to a new file), save the project,
  and the next time you open it the same files come back in their tabs, on the one you were
  looking at. Opening another project or starting a new one now closes the last project's
  files (asking first about unsaved edits in them).

For AI control: `copy_notes`, `cut_notes` and `paste_notes` do the same for agents.
`render_track` renders from the start of the song too, and the files `open_audio_editor` opens
are saved with the project and reopened by `open_project`.
